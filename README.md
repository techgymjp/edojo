# 風雲江戸城（Fūun Edo-jō）

江戸城に忍び寄る忍者を、小舟に乗った岡っ引きが **投げ銭** と **投げ輪** で召し捕るブラウザ用 3D アクションゲームです（three.js）。
外堀の内側は江戸時代のお濠・水運・石垣・城・町並み、外堀の外は今の東京のビルで作っています。

`index.html` を Web サーバーで開けば遊べます（ビルド不要。`python3 -m http.server` など。ES Modules を使うので `file://` では動きません）。
GitHub Pages は「Deploy from a branch」（`main` の `/ (root)`）で公開します（ビルド不要。`.nojekyll` で Jekyll の処理を止めています）。

## 遊び方

明け六つ。外堀の外のビルの屋上に忍者が現れ、**ムササビの術** で外堀へ飛び込みます。
「どどん！」**水遁の術** で水に潜り、竹筒だけを水面に「ぴょこん」と出して外堀を渡り、岸を這い上がるとビルの屋根伝いに走って内堀へ飛び込み、内堀の石垣・土手へ向かって進みます。
主人公は浅草橋の手前（神田川）から小舟で出ます。「内堀へ」の矢印に沿って、隅田川・日本橋川・外堀（常盤橋〜山下）を回り、日比谷濠から内堀へ入ります。風景は 10 分で 1 日（明け六つ → 昼 → 夕方 → 夜）。
石垣・土手に着くと登りはじめ、登り切られる（内堀の中に入られる）と負けです。外堀を抜けられても、内堀の中に入られなければ大丈夫。
88 人の忍者を全員召し捕ればクリア（忍者は 10 分のあいだにランダムな時刻で、小舟と関係なく動き出します。小舟が 220m 以内に近づくと、その前でも誘い出されて飛び込みます）、花火が上がります。

| 操作 | パソコン | スマホ |
| --- | --- | --- |
| 舵 | `A` `D`（跳んでいるときも、お濠の幅の中で） | 画面の左をなぞる |
| 加速 | `W`・`↑` を長押し（長いほど速く）、`S` でブレーキ | スティックを前へ |
| ジャンプ | `Space`（長押しで高く。速いときは舟ごと、遅いときはお侍だけ） | 「ジャンプ」長押し |
| ぜに（投げ銭・水の中の忍者専用・5 連射） | `J`／左クリック | 「ぜに」 |
| なわ（投げ輪・長距離） | `K`／右クリック | 「なわ」 |
| 視点 | `Q` `E`・ホイール、`C`（見下ろしに切り替え） | 画面の右をなぞる、「視」ボタン |
| 一時停止 | `P`／`Esc` | 「止」 |

- **ぜに**：水遁の術で水の中を渡っている忍者（竹筒）専用。40m 以内の竹筒へ、瀬戸内の海賊王の鉄砲と同じ光の弾で 5 連射。屋上・空中・陸・石垣の忍者は投げ輪で。
- **なわ**：遠くまで届く（海賊王の大砲の役）。当たればその場で召し捕る。動く相手には外れることがあり、投げ直しに時間がかかる。
- 狙う相手は自動で選びます（パソコンはマウスを向けた方を優先）。
- **ワープ**：実際はつながっていない内堀どうし（半蔵門・外桜田門の土橋など）には水色の渦のワープがあり、向こう側のお濠へ出られます。内堀と外の川・外堀は日比谷濠〜山下の堀だけでつながります。
- **ミニマップ**：ターザン大東京と同じ国土地理院の淡色地図（今の地図）にお濠を重ねて表示。外堀では外堀の全体、内堀に来たら 2 倍に拡大。
- **カメラ**：小舟が通ってきた水の上をたどって後ろにつき、カメラと小舟のあいだの建物は透かして消す。
- 難しさは `js/main.js` の `CFG`（忍者の数・出てくる間隔・泳ぐ速さ・登る速さ・投げ銭と投げ輪の届く距離など）で変えられます。

## 再現しているもの

- **お濠と川**：国土地理院ベクトルタイルの今の水面（内堀・日本橋川・神田川・隅田川・外堀の残り）に、埋め立てられた堀・運河を国土地理院「明治期の低湿地」（明治前期の古地図の水部）から当時の形と幅で戻しています（外堀・汐留川・京橋川・楓川・三十間堀・八丁堀・築地川・龍閑川・浜町川・神田の堀など）。古地図のずれは 600m の区画ごとに今の川・お濠に合わせて直しています。明治の地図に出ない真田濠・溜池まわりは想像で引いています（`tools/fetch_swale.py`・`tools/build_map.py`）。
- **橋**：今の橋。国土地理院の道路の線が水を渡る所に、道の幅のコンクリートの橋を架けています（お城の門の橋だけは木の橋）。
- **電車**：ターザン大東京の総武線（秋葉原へ上がる高架・黄色い電車）・中央線（万世橋のレンガ高架・オレンジの電車）・外濠ぞいの中央・総武線各駅停車を地形の上に置き、電車を走らせています。
- **外堀の輪**：神田川（牛込〜小石川〜筋違〜浅草橋）・隅田川・日本橋川・外堀で囲まれた所を江戸時代に、その外を今の東京にしています。
- **高さ**：町人地・武家地・内郭（吹上・西の丸・北の丸・西の丸下）・本丸／二の丸／三の丸の 4 段。段の境目は石垣（打込接ぎ）、千鳥ヶ淵・半蔵濠・桜田濠と外堀の西（牛込濠〜弁慶濠）は今のお濠と同じく芝の土手。城の石垣の上には白い土塀。
- **城**：寛永度天守（天守台の上に五重、銅瓦、金の鯱）、伏見櫓・富士見櫓・桜田巽櫓（位置は皇居ランナーと同じ）と石垣の上の二重櫓、本丸・二の丸・西の丸の御殿。
- **門**：内堀の門（大手門・外桜田門・半蔵門・坂下門・和田倉門・馬場先門・日比谷門・平川門・北桔橋門・竹橋門・清水門・田安門・西の丸大手門）と外堀の見附（一ツ橋・雉子橋・神田橋・常盤橋・呉服橋・鍛冶橋・数寄屋橋・山下・幸橋・虎ノ門・赤坂・喰違・四谷・市ヶ谷・牛込・小石川・筋違橋・浅草橋）。枡形（高麗門と渡櫓門）。
- **橋**：擬宝珠の欄干の木の反り橋。門の橋と、日本橋・江戸橋・一石橋・鎌倉橋・昌平橋・水道橋・両国橋・新大橋・永代橋。向きと長さは水面の形から決めています。
- **町並み**：町人地は碁盤の目の町家、河岸は白壁の土蔵、武家地は長屋で囲んだ大名屋敷、内郭は松。
- **今の東京**：皇居ゾーンの外は、ターザン大東京（techgymjp/tarzan）の街をそのまま使用（PLATEAU のビルの実際の輪郭と高さ、首都高の高架、東京タワー・東京駅・ニコライ堂・秋葉原の電気街の看板・電車・テックジムのアドバルーンなど。`js/tokyo/`）。お濠の上と皇居ゾーンに建つビルは描かない。ターザン大東京の範囲の外は PLATEAU の箱のビルで埋める。
- **地形**：国土地理院の標高タイル（DEM5A：航空レーザー測量の 5m メッシュ。ない所は 5B・10B）で、地面全体に実際の高低差を付けている（山の手の台地・坂・お茶の水の谷・下町の低地・本丸の台地など）。お濠と川の水面の高さも標高データから場所ごとに決め（千鳥ヶ淵・半蔵濠は高く、日比谷濠・隅田川は低い）、戻した江戸の堀はまわりの道より 3.2m 低くしている。ビル・首都高・名所も地形の上に建てる。
- **水面**：皇居ランナーと同じ、景色が映り込んでさざ波でゆれる水面。

## ファイル構成

- `index.html` / `style.css` — 画面と UI
- `js/main.js` — 起動・入力・小舟・忍者・投げ銭と投げ輪・HUD・難しさ（`CFG`）
- `js/world.js` — 地図の読み込み、地面・石垣・土手・水面
- `js/edo.js` — 町並み・城・門・橋・ワープ・今のビル・アドバルーン
- `js/models.js` — 小舟・岡っ引き・忍者・竹筒・寛永通宝・天守・櫓・門・橋の 3D モデル
- `js/audio.js` — 効果音と BGM、`js/fireworks.js` — 花火
- `data/map.png` — 地図（0 水 / 1 町人地 / 2 武家地 / 3 内郭 / 4 本丸 / 5 今の東京、3m/画素）、`data/world.json` — 範囲・外堀の輪・ワープ、`data/bld.json` — 今のビル
- `data/terrain.png`・`data/water.png` — 地形と水面の高さ（3m 格子。R*256+G = (高さ+20)*200）
- `js/rail-data.js` — JR の線路（国土地理院の鉄道データ。地上・高架。`python3 tools/fetch_rail.py > js/rail-data.js`）
- `js/shutoko-data.js` — 首都高（国土地理院の道路データ。地上・高架・トンネル。`python3 tools/fetch_shutoko.py > js/shutoko-data.js`）
- `tools/` — データを作るスクリプト（`python3 tools/fetch_dem.py`（国土地理院の標高タイル）→ `python3 tools/fetch_water.py > data/src/water.json` → `python3 tools/fetch_plateau_mvt.py 35.650 35.710 139.720 139.802 4 > data/src/plateau.json` → `python3 tools/build_map.py` → `python3 tools/patch_map.py`（手直し: 新川の河口・汐留の池） → `python3 tools/build_terrain.py`）

## Android アプリ

Capacitor で Android アプリにしています（パッケージ名 `jp.techgym.edojo`。ゲームのファイルはアプリに同梱し、オフラインでも遊べます）。
作り方は techgymjp/jet-fighter の `docs/ANDROID_PORTING.md` と同じ構成です。

- 動作確認用の APK（デバッグ署名・テスト広告）: main への push のたびに GitHub Actions がビルドし、Release `android-latest` に載せます
  - リリース画面: https://github.com/techgymjp/edojo/releases/tag/android-latest
  - APK 直接: https://github.com/techgymjp/edojo/releases/latest/download/edojo.apk
  - スマホで読み取る QR コード（リリース画面）: `docs/apk-qr.png`

  ![APK の QR コード](docs/apk-qr.png)

- Google Play 用の署名付き AAB: リポジトリの Secrets（`ANDROID_KEYSTORE_BASE64` など 4 つ）があるとき、Actions の Artifact `edojo-release-aab` に出ます（本番広告）
- 広告（AdMob）: バナーはタイトル・一服・結果の画面だけ。全画面広告は出陣・もう一度・再開・タイトルへ戻るとき。リワード広告は、本丸に忍び込まれたときに見ると、その曲者を押し返して続けられます（1 ゲーム 3 回まで。召し捕りの数は増えず、結果とシェアに「やり直し N 回」と出ます）
- 手元でビルドするとき: `npm ci` → `npm run android:sync` → `npm run android:open`（Android Studio）
